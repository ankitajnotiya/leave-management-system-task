#  Leave Management System Task

A streamlined full-stack tool to manage employee leaves and automate workforce operations.

## Key Features

• Smart Application: Multi-step leave form with date validation.

• Auto-Balance: Real-time leave deduction upon approval.

• Admin Control: One-click dashboard for manager reviews.

• Full Tech Stack: React.js, Tailwind CSS, Django, & DRF.

## 🛠 Tech Stack

• Frontend: React, TypeScript, Tailwind CSS, Framer Motion.

• Backend: Python, Django, Django REST Framework.

• Database: SQLite.

##  Quick Start

### 1. Backend
```bash
cd backend
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### 2. Frontend
```bash
cd frontend
npm install
npm run dev
```
